Confluence MCP 연결 선택 · 위키 자동 읽기용

회사 위키 URL만 주면 자동으로 페이지를 읽게 해주는 설정입니다. Claude Code, Codex, Gemini CLI 모두 지원합니다.

1
Confluence 프로필 → 환경설정 → 개인용 액세스 토큰 → 토큰 만들기 (이름: mcp, 만료: 1년)
생성된 토큰을 바로 복사 — 창 닫으면 다시 볼 수 없음!
2
~/.zshrc 또는 ~/.bashrc 에 추가 후 source ~/.zshrc
export CONFLUENCE_URL="https://wiki.yourcompany.com" export CONFLUENCE_PERSONAL_TOKEN="복사한-토큰"
3
mcp-atlassian 설치 (버전 고정 필수 — uvx는 버전 충돌 주의)
uv tool install "mcp-atlassian==0.21.0" --with "fastmcp==2.14.0" --force
4
AI 도구별 설정 파일에 아래 내용 추가
Claude Code: ~/.claude/settings.json · Gemini: ~/.gemini/settings.json · Codex: ~/.codex/config.toml
"mcpServers": { "mcp-atlassian": { "command": "/Users/본인계정/.local/bin/mcp-atlassian", "env": { "CONFLUENCE_URL": "https://wiki.yourcompany.com", "CONFLUENCE_PERSONAL_TOKEN": "복사한-토큰" } } }
5
Claude Code 재시작 → /mcp 입력 → mcp-atlassian ✓ Connected 확인
🪟 Windows 사용자 — 동일 단계, 명령어만 다릅니다
단계 2 — PowerShell에서 환경변수 영구 등록 (재시작 불필요)
[System.Environment]::SetEnvironmentVariable("CONFLUENCE_URL", "https://wiki.yourcompany.com", "User") [System.Environment]::SetEnvironmentVariable("CONFLUENCE_PERSONAL_TOKEN", "복사한-토큰", "User")
💡 GUI: 제어판 → 시스템 → 고급 시스템 설정 → 환경 변수 → 사용자 변수
단계 3 — uv 미설치 시 먼저 설치
# uv 설치 (미설치 시) powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex" # mcp-atlassian 설치 (Mac과 동일) uv tool install "mcp-atlassian==0.21.0" --with "fastmcp==2.14.0" --force

설정 파일: %USERPROFILE%\.claude\settings.json · %USERPROFILE%\.codex\config.toml

🔗 위키 URL만 주면 되나요?

네. 상위 페이지 URL 하나만 주면 하위 페이지 3개까지 자동으로 읽습니다. MCP 연결이 필요합니다.

📋 처음엔 어떤 경로가 편한가요?

MCP 없이 빠르게 시작하려면 [B] 문서 붙여넣기를 추천합니다. 요구사항 페이지만으로도 충분히 시작 가능합니다.

🚫 plan.md에 기술 스택을 써도 되나요?

안 됩니다. React, Spring Boot 등 프레임워크명은 금지입니다. "화면 작업만으로", "서버 호출 없음"으로 표현합니다.

🤖 Codex에서도 동일하게 동작하나요?

네. Codex도 SKILL.md를 직접 탐색해 동일하게 실행하며, MCP 연결 시 위키 자동 읽기([A] 경로)도 지원합니다. MCP 미연결 시 [B] 경로(붙여넣기)를 사용합니다.

⏱ 왜 5~10분이 걸리나요?

GPT-5.4 xhigh extended reasoning 모델 특성입니다. Claude Code는 보통 2~3분으로 더 빠릅니다.

🖼 위키 이미지도 PPT에 들어가나요?

Confluence의 이미지는 인증 제한으로 자동 다운로드가 안 됩니다. 브라우저에서 수동으로 저장 후 cases/{케이스명}/images/에 넣으면 자동 삽입됩니다.
