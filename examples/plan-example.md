# Blog Comment Moderation — Plan

> **Note**: This is a fictional example created for demonstration purposes.
> All names, systems, and URLs are placeholders.

---

## 1. Problem & Intent

- **이 작업이 필요한 이유**: 블로그 플랫폼에 댓글 기능이 추가된 이후 스팸·혐오 표현이 하루 평균 120건 이상 발생하고 있으나, 현재는 사후 신고 처리만 가능하다. 운영팀이 수동으로 확인하는 데 평균 48시간이 걸려 브랜드 이미지 손상 리스크가 커지고 있다.
- **지금 이 작업을 하는 이유**: Q2 브랜드 안전성 OKR 달성을 위해 이번 분기 내 사전 차단 기능이 필요하다. 리포트에 따르면 미처리 혐오 댓글 노출 후 신규 가입 전환율이 18% 하락했다.
- **이번 케이스에서 검증하려는 가설**: AI 1차 필터링이 운영팀 수동 검토 부담을 60% 이상 줄이면서도 정상 댓글 오탐률 2% 미만을 유지할 수 있다.

## 2. In-Scope

- AI 기반 댓글 1차 자동 분류 (승인 / 검토 대기 / 자동 차단)
- 운영자 검토 큐 화면 — 보류 댓글 목록, 승인·거절·영구 차단 액션
- 작성자 알림 — 댓글이 검토 중이거나 거절될 때 이메일 발송
- 블랙리스트 키워드 관리 — 관리자가 직접 단어 추가·삭제
- 검토 결과 감사 로그 (30일 보관)

## 5. UX / UI Guardrail

- **화면 정책**: 검토 큐는 별도 어드민 메뉴 (`/admin/comments/review`)로 분리. 기존 블로그 독자 화면과 완전히 격리.
- **컴포넌트 재사용**: 기존 어드민 공통 테이블 컴포넌트 사용. 신규 컴포넌트 최소화.
- **상태 표시**: 보류 댓글은 본문 아래 "검토 중 댓글입니다" 배너 표시. 작성자에게만 보임.
- **버튼 규칙**: 승인·거절은 단일 클릭. 영구 차단은 확인 다이얼로그 필수.
- **알림**: 이메일은 발송 후 재발송 불가. 거절 사유 텍스트는 30자 이내 선택형.

## 6. Domain Rules

- **자동 분류 기준**:
  - 신뢰도 ≥ 0.90 → 자동 승인 (즉시 게시)
  - 0.60 ≤ 신뢰도 < 0.90 → 검토 대기 (운영자 큐)
  - 신뢰도 < 0.60 또는 블랙리스트 매칭 → 자동 차단 (작성자에게 거절 알림)
- **블랙리스트 우선**: AI 결과와 무관하게 블랙리스트 키워드 포함 시 항상 자동 차단.
- **검토 큐 SLA**: 보류 댓글은 접수 후 24시간 이내 처리. 초과 시 운영 리더에게 알림.
- **감사 로그**: 승인·거절·차단 모든 액션에 처리자 ID·시각·사유를 기록.
- **재검토 불가**: 자동 차단된 댓글은 복구 불가. 작성자는 새 댓글 작성만 가능.
- **게시 지연 없음**: 자동 승인 경로는 실시간 게시. API 응답 3초 초과 시 검토 대기로 fallback.

## 7. Integration

- **AI 분류 API**: 내부 ML 플랫폼 (`/api/ml/classify`) — REST, JSON 요청/응답
- **이메일 알림**: 기존 알림 서비스 (`notification-service`) 재사용. 신규 템플릿 2종 추가 필요.
- **어드민 인증**: 기존 어드민 SSO 통과 시 댓글 검토 권한 자동 부여.
- **연동 방식**: 모두 내부 REST API. 외부 망 연동 없음.
- **실패 처리**: AI API 응답 3초 초과 → 검토 대기 큐로 자동 전환 (graceful degradation).

---

## 8. Permission / Security

- **볼 수 있는 역할**: 어드민 (`ROLE_ADMIN`), 콘텐츠 운영자 (`ROLE_CONTENT_OPS`)
- **수정 가능 역할**: 승인·거절은 `ROLE_CONTENT_OPS` 이상. 영구 차단·블랙리스트 편집은 `ROLE_ADMIN` 전용.
- **민감 정보**: 검토 큐에 작성자 이메일 노출 금지. 닉네임·작성 시각만 표시.
- **감사 로그**: 30일 보관 후 자동 삭제. 다운로드는 `ROLE_ADMIN` 전용.
- **블랙리스트**: 어드민 화면에서만 조회·편집 가능. API 응답에 목록 포함 금지.

## 9. Acceptance Criteria

- [ ] 댓글 작성 시 3초 이내에 AI 분류 결과가 반영된다.
- [ ] 신뢰도 ≥ 0.90 댓글은 즉시 게시되고 큐에 들어오지 않는다.
- [ ] 블랙리스트 키워드가 포함된 댓글은 AI 신뢰도와 무관하게 자동 차단된다.
- [ ] 운영자가 검토 큐에서 승인/거절/영구 차단을 1클릭으로 처리한다 (영구 차단은 확인 다이얼로그 포함).
- [ ] 거절 시 작성자에게 이메일이 1회 발송된다.
- [ ] 감사 로그에 처리자 ID·시각·사유가 기록된다.
- [ ] AI API 장애 시 댓글이 검토 대기로 fallback되며 서비스가 중단되지 않는다.
- [ ] `ROLE_CONTENT_OPS` 미만 역할로 검토 큐 접근 시 403 반환.

## 10. Test Scenario

- **Happy Path**
  - 일반 댓글 작성 → AI 신뢰도 0.95 → 즉시 게시 확인
  - 경계값 댓글 (신뢰도 0.75) → 검토 큐 진입 → 운영자 승인 → 게시 확인
  - 운영자 거절 → 작성자 이메일 수신 확인

- **Validation**
  - 블랙리스트 키워드 포함 댓글 → 신뢰도 무관하게 자동 차단
  - 빈 댓글, 특수문자만 있는 댓글 → 기존 유효성 검사 통과 여부

- **Failure / Edge Case**
  - AI API 응답 3초 초과 → 검토 대기 큐로 fallback, 게시 차단 없음
  - AI API 완전 다운 → fallback 동작, 알람 발생
  - 동시 검토 큐 처리 (두 운영자가 같은 댓글 동시 처리) → 선착순 처리, 나머지는 "이미 처리됨" 안내

- **Permission**
  - `ROLE_CONTENT_OPS` → 승인/거절 가능, 영구 차단·블랙리스트 편집 불가
  - `ROLE_ADMIN` → 모든 기능 가능
  - 미인증 → 검토 큐 접근 시 401

- **Integration**
  - 알림 서비스 장애 시 이메일 미발송되어도 댓글 처리 계속 진행 (best-effort)
  - AI API 응답에 작성자 PII 미포함 확인
